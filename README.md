# AI Content Generator

A simple AI Content Generator built with Streamlit and Groq.

## Features

- Blog Generator
- Email Writer
- Instagram Caption
- LinkedIn Post
- Product Description

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Add API Key

Create:

.streamlit/secrets.toml

Add:

```toml
GROQ_API_KEY="your_api_key"
```

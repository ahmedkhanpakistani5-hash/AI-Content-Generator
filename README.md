# 🤖 AI Content Generator

An AI-powered content generation web application built with **Python, Streamlit, and Groq API**.

The application allows users to generate different types of content by entering a topic, selecting a tone, and choosing the desired content length.

## 🚀 Features

- 📝 Blog Generator
- 📧 Email Writer
- 💼 LinkedIn Post Generator
- 📱 Instagram Caption Generator
- 🛍️ Product Description Generator
- 🎯 Multiple content tones
- 📏 Different content lengths
- ⚡ Fast AI-powered generation
- 🌐 Simple and user-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- LLM / Generative AI
- GitHub

## 🧠 How It Works

1. Select the type of content you want to generate.
2. Enter your topic or idea.
3. Select the desired tone.
4. Select the content length.
5. Click the generate button.
6. The AI generates the requested content.
